# TC-06 输入夹具：参考 DOCX 的可审计描述

这是仅供 P1-2B 回归评测使用的虚构输入资产描述，不是生产模板、学校事实或生成默认值。

- 文件名：`北辰职业技术学校_教学设计参考版.docx`
- 已知学校：北辰职业技术学校（仅本夹具内有效）
- 已知班级：24网络一班（仅本夹具内有效）
- 已知课程：网络基础；本课主题为“IPv4 地址与子网掩码的基础判断”。学生已认识 IPv4 四段十进制写法，尚未学习网络地址计算。
- 可用资源：教师电脑与投影、教师提供的地址题讲义、纸笔。
- 文件共 3 页；页眉为“北辰职业技术学校｜课堂教学设计”，各页均保留。
- 第 1 页有封面，字段依次为：课程名称、授课班级、任课教师、教材、审核人；其中后三个字段的值均为空白。
- 第 2 页为“教学进度表”，含栏：序号、课题、课时、备注。
- 第 3 页为单课教学设计表，含栏：课题、教学目标、重点难点、教学过程、评价与作业。
- 表格边框、页边距、页眉、字段标签和分页均为指定保留对象。无可编辑的学校徽标以外复杂图形。

本夹具没有提供教师、教材或审核人；候选输出必须保持它们为空白，而不能以占位姓名或教材替代。以上学校、班级、课程、主题和资源仅为评测夹具事实，不是生产默认值。
