# 声明式教案模板 (Template JSON) 规范与表达式指南

本项目的文档模板使用声明式 JSON 文件描述，完全解耦文档骨架与业务数据。

---

## 1. 模板顶级结构

一个标准模板 JSON 包含三大顶级区域：

```json
{
  "template_id": "default_vocational",
  "name": "中职标准化教学设计模板",
  "version": "2.0.0",
  "pagination": { "lesson_start": "new_page" },
  "cover": { ... },          // 封面区域定义
  "schedule": { ... },       // 授课进度表定义
  "lesson_table": { ... }    // 各课时大表与多环节结构定义
}
```

---

## 2. 表达式求值语法 (`TemplateManager`)

模板中使用轻量 Jinja-like 双大括号语法进行动态数据绑定：

*   **简单字段绑定**：`"{{ cover.title }}"` 或 `"{{ lesson.title }}"`
*   **默认值过滤 (Fallback)**：`"{{ cover.title | default('教  学  设  计') }}"`
*   **循环项绑定 (Repeater)**：`"{{ item.stage_index }}\n{{ item.stage_name }}"`
*   **纯静态文本**：直接使用 `"text": "课  题"`，无需加标签。

---

## 3. 核心区块定义

### 3.0 分页策略 (`pagination`)

- `lesson_start: "new_page"`：每个课次从新页开始，适合学校要求按课次独立归档的教案。内容较长时，反思填写区可能占据课次末页，这是版面容量的正常结果。
- `lesson_start: "flow"`：第一课仍与进度表分页，后续课次自然接续，适合优先减少留白和总页数的场景。

不要根据 LibreOffice 页数自动切换策略。应按学校格式要求选择，并在 Word/WPS 中验收。

### 3.1 封面区域 (`cover`)
- `top_spacing_paragraphs`: 顶部空行数。
- `title`: 大标题样式与绑定（字体、字号、加粗、对齐）。
- `subtitle`: 副标题样式与绑定。
- `info_table`: 课程信息双列表格几何与样式（总宽度、两列列宽 `[2000, 3800]`、边距与内外文字样式）。
- `school` & `date`: 落款学校与日期。

### 3.2 授课进度表 (`schedule`)
- `title`: 标题样式与对齐。
- `table`: 包含 `tbl_style`, `cant_split`, `grid_cols_dxa`（10列标准布局）。
- 自动渲染第 0 行统计信息、第 1 行学时分类、第 2 行表头、动态周次内容行及尾部备注行。

### 3.3 课时大表 (`lesson_table`)
- `title_header`: 课时序号小标题（如“教案 1”）。
- `table`: 包含 `grid_cols_dxa`（如 4 列标准布局 `[1438, 1153, 4235, 1696]`）与单元格边距。
- `sections`: 声明表格内部各种类型的行块：
  1. **`static_row`**：单行定义，支持单元格 `colspan`、对齐、绑定。
  2. **`row_group`**：多行组合，第 0 列自动跨行合并（如“教\n学\n目\n标”）。
  3. **`static_rows`**：基于 `items` 列表渲染的重复键值行（如重点、难点、教法、学法等基础 6 行）。
  4. **`repeater`**：动态教学环节循环。循环遍历 `lesson.stages`；默认每个环节一行。设置 `paragraph_groups: true` 时，将非整格加粗的内容按“连续小标题＋首段正文”及其余正文段分为短排版行，不修改内容 JSON。相邻排版行隐藏内部横线，环节标签只在首行出现，设计意图按自身段落分布于同环节的行中；不再纵向合并为超长单元格。默认模板启用此项，以改善 Word 中的孤立标题和段尾孤行。
  5. **`reflection_blank`**：自动生成反思空白行（支持指定默认空白行数）。

短排版行使用行级禁止跨页；较长段落组会给出警告并保留跨页能力，优先于模板的全表禁止跨页设置。Word 对超页且禁止拆分的行可能裁切内容，见 [Microsoft 的实现说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/a55188f7-2443-4c17-ba5a-75999085bab4)。长度判断只是保守估算，不能替代目标编辑器验收。自定义字号、列宽或长单段内容尤其需要逐页核验；内容适合时可补充自然段落，不得通过删减教学内容消除分页问题。

`repeater` 在 `paragraph_groups: true` 下另支持两个可选项，默认模板均开启；旧模板缺省时维持旧布局：

- `balance_columns: true`：按列宽、字号和行距估算原子段落组高度，将短列的相邻完整段落组排入同一物理行，减少两列逐段硬对齐造成的空隙。不改变各列文字顺序、空行或标题与首段正文的分组，不设置固定行高。超长首块不继续吸附邻段，仍走可跨页安全回退。
- `continuous_borders: true`：教学过程使用表格级连续外框，内部排版行不绘制横线，环节边界保留横线；避免单元格 `nil` 边框覆盖续页下边框。当前适配默认黑色细线网格，自定义边框颜色/粗细须另验。
- `paragraph_space_before_pt` / `paragraph_space_after_pt`：只控制短排版行内自然段的段前、段后间距。默认模板设为 `0.0`，保留正文 12 pt 和 1.08 倍行距，以减少多段正文累计造成的页尾浪费；未配置时沿用样式文件的常规段间距。
- `max_unsplit_height_fraction`：短排版行占单页可用高度的安全上限，默认 `0.82`。低于上限的行整体移到下一页，避免 Word 在单元格内部续页时裁切页顶文字且无法重复表头；超过上限的行必须允许跨页，以免 `cantSplit` 导致整行裁切。它仍是保守估算，不能替代 Word/WPS 逐页检查。

短排版行内部的标题关联由原子分组及行级禁止跨页承担，不将正文段落的 `keep_with_next` 延伸到下一物理行；两行重复表头仍保持关联。双列平衡是局部启发式，不是目标编辑器的分页引擎，不保证总页数减少。每课另起一页和反思填写区导致的末页留白应保留，除非用户明确调整。
